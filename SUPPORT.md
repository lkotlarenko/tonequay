# Getting help

Read the [user guide](docs/USER_GUIDE.md),
[installation/troubleshooting guide](docs/FM1_STUDIO.md) and
[known limitations](docs/FM1_STUDIO_TEST_REPORT.md) first. For reproducible bugs,
open an issue with the app version, distribution, Wayland/X11 session, firmware
version/source and selected audio/MIDI ports. A screenshot or short log helps;
remove personal information and do not attach proprietary firmware or saves.

Check the MIDI inspector before assuming every MiniLab preset uses the same
CCs. Try Panic for held notes, and use Firmware MIDI versus FM-1 panel according
to whether you want guest MIDI messages or physical panel control.

For security concerns follow [SECURITY.md](SECURITY.md). Community support has no
guaranteed response time. Firmware bugs may belong with the original creator;
please isolate the behavior before reporting it upstream.
