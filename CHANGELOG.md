# Changelog

## 0.1.0 — 2026-11-14

- Introduce Tonequay, based on Joakim Eriksson’s FM-1 emulator.
- Native firmware library, verified original-source downloads and offline cache.
- Persistent configurable local firmware folder.
- Interactive instrument panel, guest MIDI and MIDI panel control, MiniLab defaults
  and MIDI Learn.
- Native audio with bounded transport, isolated saves and backup management.
- Compact dark/light interface, original application icon and stable draft/apply
  accessibility controls.
- Linux AppImage packaging and documented test/compatibility limitations.
