# Community conduct

Be respectful, constructive and considerate of people with different experience
levels. Critique ideas and code, not people. Harassment, threats, discrimination,
sexualized attention and publication of private information are unacceptable in
project spaces.

The repository maintainer, @lkotlarenko, may edit or remove inappropriate content,
close discussions or restrict participation. Responses should account for the
severity and context of the behavior. Where safe, explain the decision and allow
clarification. Do not retaliate against people who raise concerns.

For an ordinary moderation issue, ask the maintainer to review the relevant
GitHub discussion. Do not publish sensitive personal details; request a private
contact channel first if one is needed. This project does not currently promise
a staffed private moderation service or a fixed response time.
